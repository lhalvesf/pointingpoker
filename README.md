## About Pointing Poker 🃏
Pointing Poker is a generic name used by scrum teams for the sessions where the work effort for specific tasks are estimated. 

This project easy-to-use pointing poker tool to facilitate the day-by-day of scrum teams to estimate the work effort needed to their deliver tasks.

### Features:
- Real time rooms.
- Up to 50 simutaneous users by session/room.
- Private sessions (provide a token to access).
- Tickets can easily shared during the vote sessions.
- BRB card to point out when some user is unable to vote at that round.

Users users are a free to choose between two measurement strategies to vote their estimates: 
- Fibonnaci's golden ratio.
- t-shirt size.
